# BBF DataModel Viewer & Editor - 起動・操作手順書

本手順書では、Broadband ForumのDataModel (TR-181, TR-196, TR-262) を可視化し、NETCONFの `&lt;edit-config&gt;` のXMLペイロードを生成するアプリケーションの起動方法と操作方法について説明します。

---

## 1. 動作要件・前提条件

本アプリケーションを実行するには、以下の環境がインストールされている必要があります。

* **Python 3.10 以上** (および パッケージ管理ツール `uv`)
  * `uv` が未インストールの場合は、公式ドキュメントに従って [uvのインストール](https://github.com/astral-sh/uv) を行ってください。
* **Node.js (v18 以上推奨)** および `npm`

---

## 2. 起動手順

本アプリケーションは、Pythonによる「バックエンド」と、Reactによる「フロントエンド」の2つのサーバーをそれぞれ起動する必要があります。
Windows環境向けに、両方を一括で起動できるPowerShellスクリプト (`start.ps1`) を提供しています。

1. ターミナル (PowerShell) を起動し、プロジェクトのルートディレクトリ(`bbf_viewer`)に移動します。
2. 初回起動時は `-Install` フラグをつけて実行し、依存関係を自動インストールします。

   ```powershell
   .\start.ps1 -Install
   ```

3. 2回目以降の通常起動は以下のコマンドを実行します。

   ```powershell
   .\start.ps1
   ```

4. 起動が完了すると、自動的にバックエンド(8000番ポート)とフロントエンド(5174番ポート等)が立ち上がります。
5. ターミナルに表示されたURL (例: `http://localhost:5174/`) をCtrlキーを押しながらクリックするか、ブラウザにコピーしてアクセスしてください。
6. 終了する場合は、フロントエンド・バックエンド共に `Ctrl+C` で一括停止できます。

---

## 3. 操作手順

ブラウザでフロントエンドにアクセスすると、「BBF DataModel Viewer」が表示されます。

### 3.1. DataModelの選択

* 画面左上のドロップダウンメニューから、閲覧したいBroadband ForumのXMLモデル（例: `tr-181-2-18-0-cwmp.xml`, `tr-196-2-0-3.xml`, `tr-262-1-0-0.xml`）を選択します。
* 選択すると、直下にそのモデルの階層構造（ツリー）がロードされます。

### 3.2. モードとツリー・検索操作

左側パネル上部のタブで、目的に応じて「Viewモード」または「Editモード」を切り替えます。

* **🔎 View Mode**: すべてのパラメータ階層を表示し、内容を確認するためのモードです。
* **✏️ Edit Mode**: NETCONFの設定対象となる、書き込み権限（`readWrite`）を持ったパラメータ群のみにツリーが絞り込まれます。

**ツリーの操作:**

* 左側のツリーから `▶` アイコンをクリックして階層を掘り下げます。
  * `object` (青タグ): 子要素を持つフォルダ階層。
  * `readOnly` (グレー): 読み取り専用パラメータ。
  * `readWrite` (赤タグ): 編集可能パラメータ。
* **検索ボックス ("Search parameters...")** に文字を入力すると、部分一致したパラメータの階層のみがリアルタイムでフィルタリングされ、自動で展開表示されます。
* タグ（枠線付きパラメータ項目）をクリックすると、右側のメインパネルに詳細情報が表示されます。

### 3.3. NETCONF &lt;edit-config&gt; XMLの生成 (Editor機能)

TR-069パラメータに対する設定編集メッセージを模した、NETCONFのペイロードを出力する機能です。

1. 左側のツリーから、赤色の **`readWrite`** と表示されたパラメータをクリックして選択します。
2. 画面右下に **「Edit Configuration (NETCONF)」** というパネルが表示されます。
3. 入力フィールドに変更したい文字列（値）を入力します。（例: `TestValue`）
4. **「Generate XML」** ボタンをクリックします。
5. 画面右側のパネル（**Generated NETCONF &lt;edit-config&gt;**）に、指定した値とターゲットパスを反映したNETCONFプロトコル標準のXMLテキストがシンタックスハイライト付きで生成されます。
6. パネル右上の **「✓ Lint XML」** ボタンをクリックすると、生成されたXMLまたは手動入力したXMLの構文チェックを行い、正しいフォーマットか検証できます。
7. このXMLをコピーし、各検証用途にご利用いただけます。
