# BBF DataModel Viewer & Editor - 起動・操作手順書

本手順書では、Broadband Forumのデータモデル (TR-181, TR-196, TR-262) をブラウザ上で可視化し、TR-069におけるCWMPの `SetParameterValues` XMLペイロード（W3C SOAP 1.1規格）を動的に生成するローカルWebアプリケーションの起動・操作方法について説明します。

---

## 1. 動作要件・前提条件

本アプリケーションを実行するには、以下の環境があらかじめインストールされている必要があります。

* **Python 3.10 以上** (および パッケージ管理ツール `uv`)
  * `uv` が未インストールの場合は、公式ドキュメントに従って [uvのインストール](https://github.com/astral-sh/uv) を行ってください。
* **Node.js (v18 以上推奨)** および `npm`

---

## 2. 起動手順

本アプリケーションは、Pythonによる「バックエンドAPIサーバー」と、Reactによる「フロントエンドWebサーバー」の2つを起動して動作します。
Windows環境向けに、両方をワンクリックで一括起動できるPowerShellスクリプト (`start.ps1`) を提供しています。

1. ターミナル (PowerShell) を起動し、プロジェクトのルートディレクトリ(`bbf_viewer`)へ移動します。
2. 初回起動時は `-Install` フラグをつけて実行し、依存パッケージ（Pythonライブラリ、Nodeモジュール等）のインストールを行います。

   ```powershell
   .\start.ps1 -Install
   ```

3. 2回目以降の通常の起動は以下のコマンドで実行できます。

   ```powershell
   .\start.ps1
   ```

4. 起動シーケンスが完了すると、自動的にバックエンド(8000番ポート)とフロントエンド(5174番ポート等)が立ち上がります。
5. ターミナルに表示されたURL (例: `http://localhost:5174/`) をCtrlキーを押しながらクリックするか、ブラウザのアドレスバーにコピーしてアクセスしてください。
6. プロセスを終了させる場合は、アクティブなターミナル上で `Ctrl+C` を入力することで、両方のサーバーを一括停止・切断できます。

---

## 3. 操作手順

ブラウザでフロントエンドURLにアクセスすると、「BBF DataModel Viewer」のメイン画面が表示されます。

### 3.1. DataModelの選択

* 画面左上のドロップダウンメニューから、閲覧・編集したいBroadband ForumのXMLモデル（例: `tr-181-2-18-0-cwmp.xml`, `tr-196-2-0-3.xml`）を選択します。
* 選択すると、直下にそのモデルの階層構造（ツリー）がロードされます。本システムは BroadBand Forum の TR-106 (Data Model Template) に準拠し、グローバルな `<dataType>` 参照や `<default>` コンポーネントを再帰的にパースするため、少しだけ時間がかかる場合があります。

### 3.2. モード切り替えとツリー・検索操作

左側パネル上部のタブをクリックし、目的に応じて「Viewモード」または「Editモード」を切り替えます。

* **🔎 View Mode**: データモデル内のすべてのパラメータ階層を表示し、内容を安全に閲覧・確認するためのモードです。
* **✏️ Edit Mode**: CWMPの設定対象となる、書き込み権限（`readWrite`）を持ったパラメータ群のみにツリーが絞り込まれるXML生成用モードです。

**ツリーの操作:**

* 左側のツリーから `▶` アイコンをクリックして階層をドリルダウン（展開）します。
  * **(注)** 本アプリケーションでは利便性向上のため、最上位の `Root` ノードをスキップし、`Device.` や `FAP.` など実質的な最上位オブジェクトから直接表示します。
  * `object` (青タグ): 子要素を持つフォルダ階層。
  * `readOnly` (グレー): 読み取り専用パラメータ。
  * `readWrite` (赤タグ): 編集可能パラメータ。
* **検索ボックス ("Search parameters...")** に文字列を入力すると、部分一致したパラメータの階層のみがリアルタイムでフィルタリングされ、結果が自動展開されます。
* タグ（枠線付きのパラメータ項目）をクリックすると、画面中央のメインパネルに詳細情報がテーブル形式で表示されます。テーブルの Description や Description Type（列挙型など）は、TR-106で定義される制約規則に基づいて展開されています。

### 3.3. CWMP SetParameterValues SOAP XMLの生成

TR-069パラメータに対する設定変更要求を模した、W3C SOAP 1.1 プロトコルのCWMPペイロード（XML）を出力・検証する機能です。

1. 左側のツリーから、赤色の **`readWrite`** と表示されたパラメータをクリックして選択します。
2. 画面中央のテーブルにパラメータの詳細が表示され、その下に **「CWMP SetParameterValues Editor」** という入力パネルが出現します。
   * パラメータのパスにリスト要素 `{i}` が含まれる場合、インデックス（Instance値）の入力ボックスが自動的に表示されます。（例: `1` と入力すると `Device.FAP.PerfMgmt.Config.1.Enable` として処理されます）
3. 入力フィールドに変更したい文字列（値）を入力します。（例: `true` または `0` など）
4. **「Generate XML」** ボタンをクリックします。
5. 画面右側に広がる専用ペインに、指定した値・解決されたスキーマデータ型（`xsi:type="xsd:string"` 等）・ターゲットパスを反映した **SOAP Envelope** が生成されます。
   * 既にXMLが右ペインに存在する場合、`<SetParameterValues>` 内の `<ParameterList>` 配下に、対象プロパティの `<ParameterValueStruct>` が**追記（Append）**され、リスト全体の `arrayType`（`cwmp:ParameterValueStruct[2]`等）も自動インクリメントされます。
6. 右上にある **「✓ Lint XML」** ボタンをクリックすると、生成・表示されているSOAP XMLの構文チェックを行い、正しいフォーマットか検証できます。
7. 生成されたテキストをコピーして、CPE(ACSモックアップ側)の実機検証などに活用してください。
