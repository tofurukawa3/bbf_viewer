# Translator API 利用規約およびライセンスに関する方針

本 `translator` サブプロジェクトは、英語で記述されたBroadband Forum (BBF) のCWMP/TR-069 データモデルXMLを日本語へ翻訳・変換するための補助ツールセットです。

## 1. 利用しているAPIについて

本スクリプト群（`translate_models.py` 等）は、Pythonライブラリの `deep-translator` を用いて、GoogleがWeb上で提供している無料の翻訳エンドポイントをスクレイピングする形で利用しています（公式のGoogle Cloud Translation APIキー等を用いた商用API利用ではありません）。

## 2. API利用における責任

- 本ツールの利用者は、本ツールを実行するにあたり、Googleの公式な「利用規約（Terms of Service）」に従う必要があります。
- API側の仕様変更により、予告なく本スクリプトが動作しなくなる可能性があります。
- 不必要に過度な翻訳リクエストを連続して送信した場合、実行元のIPアドレスがGoogle側から一時的あるいは恒久的にブロック（レート制限）を受ける可能性があります。
- レート制限やブロックを回避するため、本ツールは `translation_cache.json` による翻訳結果のキャッシュ機構と、複数テキストを一度に翻訳するバッチ化ロジックを備えていますが、IPブロックの完全な回避を保証するものではありません。

## 3. 保証の否認 (As-Is 提供)

- 本翻訳機能およびその出力結果（作成される日本語化XMLファイル）は、「現状有姿（As-Is）」として提供されます。
- BBF Viewerのコアシステムを含め、本プロジェクトの作者・メンテナは、翻訳の正確性、APIの永続的な稼働、および本ツールを使用することによって生じたいかなる損害（前述のIPブロック等を含む）に対しても一切の責任を負いません。

## 4. 組み込みと改変

- 本 `translator` システムは、利用者自身がローカルで利用・改変することを前提としています。
- 高頻度あるいは商用での大規模な翻訳要件がある場合は、本ソースコードを改変し、正当なAPIキーを用いた有料APIサービス（Google Cloud, DeepL, OpenAI 等）へ接続先を切り替えることを強く推奨します。
